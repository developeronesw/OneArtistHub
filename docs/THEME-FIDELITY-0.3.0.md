# Theme Fidelity Contract — 0.3.0

The approved mockups are the design contract. The implementation must not reduce the three themes to palette swaps.

### Midnight Cinema
Framed widescreen desktop canvas; black/charcoal base; restrained warm gold; high-contrast serif artist name; cinematic full-bleed hero; luxury rectangular buttons; feature-release editorial panel; video/merch/tour modules; gold-accent player.

### Artist OS
Desktop left navigation rail; immersive blue/black artist universe; luminous modern wordmark treatment; feature-release module; dense modular content grid; rounded blue glass panels; app-like mobile layout; blue/white player.

### Neon Editorial
Asymmetrical image-led layout; oversized condensed/block headline rhythm; white-to-pink/orange headline color break; cyan frame accents; hot-pink CTAs; squared editorial cards; dense music/video/merch modules; pink/cyan player.

Each theme owns its own responsive rules for desktop, tablet and phone. Content and functionality remain shared.
